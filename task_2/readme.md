1)Метод точний у середньому
Середні значення по багатьох запусках практично збігаються з 2.6667, тобто оцінка не має систематичного зсуву.
2)Розкид зменшується як 1/√N 
При збільшенні N у 100 разів стандартне відхилення падає приблизно в 10 разів (з 0.386 до 0.039 і далі до 0.012).
Це типова збіжність Монте-Карло.
3)Метод повільний для простих функцій
Для 1D-інтеграла quad досягає похибки порядку 1e-14 за кілька десятків обчислень функції,
а Монте-Карло навіть на 10 млн точок дає лише 2-3 правильні знаки. Для гладких функцій однієї змінної quad значно кращий.
4)Де Монте-Карло виправданий 
Швидкість збіжності 1/√N не залежить від розмірності, тоді як детерміновані квадратури різко дорожчають зі зростанням 
кількості змінних. Тому метод виграє для багатовимірних інтегралів і складних областей інтегрування.
